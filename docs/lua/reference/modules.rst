Модулі розширення
=================

Для модулів, що вставляються в :ref:`роз'єм розширення <lilka-uk:extension>` Лілки v2, є окремі Lua-модулі:

=================== ============================== =========================
Модуль              Плата                          Lua
=================== ============================== =========================
002 IR              KY-005 + KY-022                :doc:`ir`
003 LORA            E22-900M (SX1262) / E22-400M    :doc:`lora`
                    (SX1268)
004 RF              nRF24L01+ / CC1101             :doc:`nrf24`, :doc:`cc1101`
005 GPS             u-blox NEO-M8N                 :doc:`gps`
006 GYRO MAGNET     BMI260 + TMAG5273              :doc:`imu`, :doc:`mag`
008 CAN             SN65HVD232                     :doc:`can`
=================== ============================== =========================

Усі вони працюють однаково:

- ``модуль.new({...})`` створює об'єкт. Усі параметри необов'язкові - типові значення відповідають
  розпіновці плати. Якщо модуль не знайдено, повертається ``nil`` і текст помилки, тому зручно писати
  ``local radio = assert(lora.new())``.
- Методи викликаються через двокрапку: ``radio:send("hi")``.
- Нічого не блокує надовго: ``receive()`` повертає ``nil``, якщо даних немає. Викликайте його в ``lilka.update``.
- Об'єкт тримає свої контакти та периферію (UART, SPI2, I2C, TWAI, RMT) зайнятими. Якщо їх уже використовує
  інший скрипт (наприклад, :doc:`сервіс <service>`), ``new`` завершиться помилкою. ``close()`` звільняє все;
  після завершення скрипта це відбувається автоматично. Можна також писати ``local radio <close> = ...``.
- Контакти модулів беруться з налаштувань Лілки: для v2 вони вже задані, а змінити їх можна INI-файлом
  у ``/sd/.lilka/config/`` (секції ``gps``, ``can``, ``ir``, ``lora``, ``rf``, ``gyro_magnet``), наприклад:

  .. code-block:: ini

      ; /sd/.lilka/config/modules.ini
      [lora]
      nss = 21

  Частину контактів можна також передати в ``new`` (наприклад, ``gps.new({rx = 44, tx = 43})``).
- Модулі, що ділять шину (``imu`` і ``mag`` - I2C; ``lora``, ``nrf24``, ``cc1101`` - SPI2), можна
  використовувати разом в одному скрипті.

Готові програми для всіх модулів - у репозиторії прикладів:
`LUA/modules <https://github.com/lilka-dev/examples/tree/main/LUA/modules>`_.

.. warning::

    Радіомодулі (``lora``, ``cc1101``, ``nrf24``) передають у ефір. Під'єднайте антену і перевірте,
    які частоти та потужності дозволені у вашій країні.
